Fenkit MCP is a [Model Context Protocol](https://modelcontextprotocol.io) server that bridges your AI agent (Cursor, Claude, Windsurf, and more) with the Fenkit task management platform. Your agent can discover tasks, create structured plans, track execution progress, and submit completion walkthroughs — all without any copy-paste.

## How it works

Fenkit MCP runs as a local MCP server alongside your AI client. The agent uses structured tools to read task context, plan work, update status, and document outcomes — keeping your Fenkit dashboard in sync automatically.

<Steps>
  <Step title="Install and configure">
    Run `npx -y fenkit-mcp setup <client>` to inject the server configuration into your AI client's config file.
  </Step>
  <Step title="Authenticate">
    Call the `login` tool from your agent. A browser window opens, you log in, and the token is saved automatically.
  </Step>
  <Step title="Select a project">
    Use `list_projects` and `select_project` to point the agent at your active Fenkit project.
  </Step>
  <Step title="Start working">
    Your agent calls `list_tasks`, picks up a task, creates a plan with `update_task_plan`, and tracks progress through to `update_task_walkthrough`.
  </Step>
</Steps>

    Separate read, write, and admin servers give your agent only the permissions it needs.

    All write operations use operation IDs and optional preview/confirmation tokens to prevent duplicate updates.
