## Prerequisites

- Node.js v18 or later
- A Fenkit account
- One of the 7 supported AI clients installed

## Setup

<Steps>
  <Step title="Run the one-line setup command">
    Pick your AI client and run the corresponding setup command. This writes all required MCP config files automatically — no manual JSON editing needed.

    <Tabs>
      <Tab title="Cursor">
        ```bash
        npx -y fenkit-mcp setup cursor
        ```
        Writes `.cursor/mcp.json` and `.cursor/rules/fenkit.mdc` in your current project directory.
      </Tab>
      <Tab title="Claude Desktop">
        ```bash
        npx -y fenkit-mcp setup claude
        ```
        Writes to `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) or `%APPDATA%\Claude\claude_desktop_config.json` (Windows).
      </Tab>
      <Tab title="Windsurf">
        ```bash
        npx -y fenkit-mcp setup windsurf
        ```
        Writes `~/.windsurf/mcp.json` and injects the Fenkit protocol into `~/.windsurfrules`.
      </Tab>
      <Tab title="Claude Code">
        ```bash
        npx -y fenkit-mcp setup claudecode
        ```
        Writes `~/.claude/config.json` and injects the Fenkit protocol into `.clauderules` in your current project directory.
      </Tab>
      <Tab title="Codex">
        ```bash
        npx -y fenkit-mcp setup codex
        ```
        Writes `~/.codex/config.toml` and `~/.codex/fenkit-instructions.md`.
      </Tab>
      <Tab title="OpenCode">
        ```bash
        npx -y fenkit-mcp setup opencode
        ```
        Writes `~/.config/opencode/opencode.json` (macOS/Linux) or `%APPDATA%\opencode\opencode.json` (Windows).
      </Tab>
      <Tab title="Antigravity">
        ```bash
        npx -y fenkit-mcp setup antigravity
        ```
        Writes `~/.gemini/antigravity/mcp_config.json` and injects the Fenkit protocol into `~/.gemini/GEMINI.md`.
      </Tab>
    </Tabs>

    The setup registers three MCP servers for your client: `fenkit_read`, `fenkit_write`, and `fenkit_admin`.
  </Step>

  <Step title="Restart your AI client">
    Restart the client to load the new MCP configuration. The three Fenkit servers (`fenkit_read`, `fenkit_write`, `fenkit_admin`) will connect on startup.
  </Step>

  <Step title="Verify the connection">
    Ask your agent to call `get_status`. It returns your current authentication state and active project.

    ```
    get_status
    ```

    Expected response when not yet authenticated:

    ```
    Authenticated: ❌ No — run 'login' first
    API URL: https://ickit-be.vercel.app/api/v1
    Active Project: None — use `list_projects` and `select_project` first
    ```

    <Note>
      If `get_status` returns an error or the tool is not found, the MCP servers did not connect. Verify that you restarted your client and that Node.js v18+ is on your shell's `PATH`.
    </Note>
  </Step>

  <Step title="Log in">
    Call the `login` tool. Fenkit MCP opens a browser window pointing to the Fenkit authentication page. Complete the login flow there — the token is captured automatically and saved to `~/.fnk/config.json`.

    ```
    login
    ```

    After successful authentication:

    ```
    ✅ Authenticated successfully! Token saved to ~/.fnk/config.json.
    ```

    If you have exactly one project, it is auto-selected. Otherwise, proceed to the next step.
  </Step>

  <Step title="Select a project">
    List your available projects, then select one to set the active context for all subsequent task operations.

    ```
    list_projects
    ```

    Example response:

    ```
    ## Projects

    - **My App** (`a1b2c3d4`) — Main product
    - **Internal Tools** (`e5f6a7b8`) — Team utilities
    ```

    Select a project by its ID (a short prefix is accepted):

    ```
    select_project a1b2c3
    ```

    ```
    ✔ Active project set to **My App** (`a1b2c3d4`)

    result_code: applied
    ```
  </Step>

  <Step title="List and load tasks">
    List tasks in the active project. By default this returns tasks with status `todo`, `in_progress`, or `in_review`.

    ```
    list_tasks
    ```

    Example response:

    ```
    ## Tasks in My App

    ### 🔵 IN PROGRESS
    - **Add OAuth support** (`22b50`) · high

    ### ⬜ TODO
    - **Refactor user model** (`9fc12`) · medium — Extract address fields into...
    - **Write API tests** (`3a8d1`) · low
    ```

    Load the full context for a specific task before starting work:

    ```
    get_task_context_compact 22b50
    ```

    This returns the task title, description, status, priority, current plan, and any previous walkthrough — all in a token-efficient format.
  </Step>
</Steps>

## What happens next

Once your agent has task context, it follows the Fenkit Task Protocol automatically:

1. Submits a structured plan with `update_task_plan` before writing any code
2. Sets the task to `in_progress` with `set_task_status`
3. Persists a walkthrough with `update_task_walkthrough` when done, which automatically moves the task to `in_review`

Your Fenkit project board updates in real time as the agent works.

<Tip>
  Search for tasks by keyword using `search_tasks` when you know what you want to work on but not the task ID.
</Tip>
